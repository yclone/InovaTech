## 🚀 **Como Usar (Qualquer Máquina)**

### **Opção 1: Clone Completo**

```bash
git clone https://github.com/yclone/InovaTech.git
cd InovaTech/FrontEnd
```

### **Opção 2: Setup Automático**

**Windows:**

```powershell
.\setup.ps1
```

**Linux/Mac:**

```bash
bash setup.sh
```

**Manual:**

```bash
npm install
cp .env.example .env.local
npm run dev
```
