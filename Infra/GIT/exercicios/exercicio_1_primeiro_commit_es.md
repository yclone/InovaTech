# Ejercicio 1: Primer Commit

1. Clona el repositorio de ejemplo:
   ```powershell
   git clone https://bitbucket.org/tu-usuario/ejemplo-repo.git
   cd ejemplo-repo
   ```
2. Crea un archivo `hello.txt` con tu nombre.
3. Agrega y haz commit:
   ```powershell
   git add hello.txt
   git commit -m "Mi primer commit"
   git push
   ```
